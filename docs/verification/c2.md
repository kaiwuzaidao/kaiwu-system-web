# C2 宿主深链接（2026-11-01）

项目白名单通过现有 CLI project sync 的 kaiwu/configs.yml 登记，仍是普通的项目级非敏感 JSON 配置。键为 workspace.deep-links；宿主从已有 GET /api/current/projects/{projectId}/configs 读取，并要求 sourceScopeId 等于当前项目。全局继承、其他项目、读取失败、重复配置或非法 JSON 整体回到首页。登记的 version 必须为正安全整数，每次修订增加版本；不在浏览器持久化配置或身份。

```yaml
- key: workspace.deep-links
  type: JSON
  default: '{"version":1,"routes":[{"prefix":"/workflow/tasks","queryParameters":["taskId","tab"]},{"prefix":"/workflow/instances","queryParameters":[]}]}'
  description: 项目宿主允许的业务子路由与查询参数
```

先用入口 CLI 的 project sync <业务后端仓目录> 查看计划，符合已授权范围后加 --apply，再读回有效配置。根据 ADR 0036，sync 只为新配置写默认值，已存在配置的当前值不会被清单覆盖；后续白名单变更须通过现有项目配置管理入口更新运行值，不能宣称重新 sync 就改变了当前值。本文未修改共享环境配置。

外层 route 严格解码一次，重复参数、非法 UTF-8、残留百分号、外部 URL、路径穿越、反斜杠、控制字符、片段、非 ASCII 和超长输入被拒绝。内层只按最长路径段前缀匹配，参数名需登记且不得重复，值仅允许规范 ASCII 子集。白名单不允许身份或凭据参数。子路由拼到后端登记的同源项目入口下，并强制使用权威项目 ID；子应用仍独立鉴权。无 route 的旧链接保留原入口行为。

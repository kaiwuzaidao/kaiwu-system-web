# Kaiwu（开物载道）端到端验收

测试按风险分层，避免把共享开发环境当成可随意写入的测试库。

| 分组 | 覆盖范围 | 启用条件 |
| --- | --- | --- |
| 默认 | 未登录跳转、登录表单校验 | 前端运行于 `E2E_BASE_URL`（默认为本机 8000） |
| 管理员只读 | 工作台、消息、个人设置、用户、项目、配置、字典、AI、GitLab、项目工厂页面及其读取接口 | `E2E_ADMIN_PASSWORD` |
| 变更 | 用户 CRUD/停用、项目/成员/角色/菜单授权、配置/字典 CRUD | `E2E_ADMIN_PASSWORD` + `E2E_ALLOW_MUTATIONS=true` |
| 生成 | BASIC_SCAFFOLD、两个 ZIP 下载、同项目二次生成拒绝 | 额外设置 `E2E_ALLOW_GENERATION=true` |

复制 `.env.e2e.example` 为 `.env.e2e` 后执行：

```bash
 pnpm test:e2e
```

套件不再使用跳过语义：缺少管理员凭据、变更许可或生成许可时会直接失败并给出缺失配置项。

变更与生成用例只允许连接到可在每轮测试后整体重置的数据库。它们会创建用户和项目；项目没有通用删除接口，项目生成更是一次性操作。AI/GitLab 的外部连通性不以生产密钥测试：只验证页面/API 不回传密钥；连接测试应在专用 Mock Provider/GitLab 环境单独启用。

当前仓库没有组织架构、登录/操作日志查询或在线会话管理页面；这些能力在需求文档中仍标为未完成，因而不会被伪装成“已覆盖功能”。相应页面与 API 落地后，应先为每个新增行为补充用例，再接入本套分层运行方式。
